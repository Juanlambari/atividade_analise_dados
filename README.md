# Análise de Dados — Teoria Geral dos Sistemas de Informação

## Sobre o projeto

Este repositório contém uma atividade acadêmica desenvolvida para a disciplina de **Teoria Geral dos Sistemas de Informação**, com o objetivo de aplicar conceitos de análise de dados na investigação de um cenário empresarial fictício.

## Objetivo

Praticar técnicas de análise, organização e visualização de dados, buscando identificar padrões, interpretar informações e apoiar a elaboração de propostas de melhoria para o cenário apresentado.

## Dados utilizados

Os dados utilizados nesta atividade são **totalmente fictícios**, elaborados exclusivamente para fins educacionais. Nenhuma informação representa necessariamente uma empresa real ou seus resultados financeiros.

## Ferramentas e tecnologias

- Python
- Pandas
- NumPy
- Matplotlib
- Excel e arquivos CSV

## Finalidade acadêmica

Este projeto foi desenvolvido exclusivamente para fins de estudo e aprendizado, como parte das atividades da disciplina. Os resultados e as análises apresentados têm caráter educacional.

---

**Observação:** Este projeto não representa uma consultoria empresarial real nem utiliza dados confidenciais de organizações.
